# Vending Machine System

A beginner-friendly C# console application.

## Features
- Display available products, prices, and stock
- Select a product by ID
- Choose a quantity
- Calculate the total price
- Validate payment and show the change
- Reduce stock after a successful purchase
- Handle invalid input and out-of-stock products

## Products
- Water: 120 yen
- Cola: 150 yen
- Tea: 140 yen
- Chips: 180 yen

## How to run
Open `VendingMachineSystem.csproj` in Visual Studio and run the project with Ctrl+F5.
